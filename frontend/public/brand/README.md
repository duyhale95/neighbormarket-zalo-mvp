# Supplied brand asset

The user supplied both PNGs during implementation. Files in this directory are
byte-for-byte copies of `assets/vinhomes-logo.png` and `assets/vinhomes-symbol.png`
at the repository root. The original colors, alpha channel and aspect ratios are
preserved. No external logo was downloaded. The wordmark is displayed with
`height: auto` and `object-fit: contain`; it is not a certification or affiliation badge.
